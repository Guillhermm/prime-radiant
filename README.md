# Prime Radiant

A burning activity calendar built on harmonized MODIS and VIIRS hotspot counts from
NASA FIRMS, for the NASA Space Apps Challenge 2026 challenge "Harmonization of MODIS and
VIIRS Hot Spots".

Status: bootstrap (milestone M0). Nothing user-facing is built yet; see
[docs/roadmap.md](docs/roadmap.md) for what is planned.

## Run the tests

Requires Node.js 20 or newer. No install step: there are no dependencies.

```sh
node --test
```

## Data

Planned: NASA FIRMS archive (MODIS Collection 6.1 and VIIRS S-NPP 375 m standard
products). Citation and acknowledgment text will be added with the pipeline (M1).
