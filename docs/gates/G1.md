# Gate G1: global extent

Date: 2026-11-15. Claim: the archive method validated for Brazil at gate V1 applied worldwide with no domain clip,
data version `202611151751` (FIRMS yearly all-countries files, `docs/data.md`, "Global build"). Checked independently
by the reviewer, the mathematician and the physicist on the production files.

**Verdict: accepted with caveats, except the type filter (rejected outside Brazil).** The global data stays published;
the app shows the `global-extent` caveat, tagged preliminary, on every global query.

| Item | Verdict | Basis |
|---|---|---|
| Arithmetic: fine to coarse tiles, `global.json` | accepted | 0 mismatches on five non-Brazil tiles; `global.json` equals the sum of all 409 coarse tiles (312 months x 3 sensors) |
| Antimeridian and polar tiles | accepted | `[175,-20,-175,-10]` returns x35y7 and x0y7; a box across 180 degrees sums correctly |
| R and K outside Brazil | accepted with caveats | No NaN or Infinity. Angola R 2.655, K 0.984 recomputed; Australia north 1.77; Siberia falls back to its 10 degree tile, 1.31; Fiji 5.03 (4.30-6.17). By tile: Yakutia 1.31, boreal Canada 1.71, Zambia/DRC 2.40, Punjab 3.22, so a global fallback (about 2.4) is wrong for boreal areas. Polar tiles hold scattered single detections on ice (a South Pole box gets a "usable" K of 1.20) |
| MODIS before 2000-11 | accepted | 2000-01 to 2000-10 null, never 0 |
| Type 0 filter | **rejected** outside Brazil | Gas flares at Hassi Messaoud (6.1E 31.8N) are type 0 in 98 of 107 months (tile R 4.1); Rumaila, the Niger Delta and Antarctica also show in 2025. FIRMS documents Type for MODIS (MCD14ML); no VIIRS definition was found |
| Country files equal the global archive | unverified | Not documented by FIRMS; to check on a sample region against a global request |
| Cell area and overpasses | accepted with caveats | One count per cell and day caps extra polar passes; cells are not equal-area, so latitudes do not compare |
| UTC days | accepted with caveats | Only the date label moves, by up to a day near the dateline |

Fix for the type filter (not built): a static-source mask of cells with archive types 1-3 plus a published gas-flare
list, then a rebuild. Persistence alone would also mask year-round savanna fires in Angola. Also open: refuse or flag
the global fallback ratio in boreal areas.

Update 2026-11-15: the static-source mask is built (gate G2, docs/gates/G2.md), and a world R in a global build is now
flagged low confidence (docs/method.md 4.3).

Sources: FIRMS attributes page, https://earthdata.nasa.gov/data/tools/firms/active-fire-data-attributes-modis-viirs
(type codes, MODIS only); FIRMS FAQ, https://www.earthdata.nasa.gov/data/tools/firms/faq; Schroeder et al. 2014,
Remote Sensing of Environment 143, the VIIRS 375 m active fire algorithm.
